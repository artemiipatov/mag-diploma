\section{Постановка задачи}
\label{sec:task}

Целью дипломной работы является разработка драйвера для системы трассировки N-Trace в многопроцессорном кластере
с архитектурой RISC-V, обеспечивающего интеграцию с подсистемой профилирования perf операционной системы Linux и предоставляющего
механизмы конфигурации аппаратных компонентов трассировки:
\begin{enumerate}
    \item Портирование и адаптация открытой реализации минимального драйвера rvtrace
    (патч riscv\_trace\_support\_v4~\cite{rvtrace_github}) для целевой платформы, включая
    устранение выявленных программных недочетов
    \item Разработка системы конфигурации компонентов подсистемы N-Trace:
    \begin{enumerate}
        \item Обеспечение интеграции адресных фильтров с интерфейсом подсистемы perf.
        \item Разработка расширенной системы конфигурации для поддержания возможности создания пресетов из userspace, потенциально
        содержащих в себе настройку регистров для каждого компонента подсистемы.
    \end{enumerate}
    \item Обеспечение работы внутри многопроцессорного кластера с N-Trace подсистемой на каждом процессоре и нетривиальной логикой
    маршрутизации внутри него.
    \item Разработка драйвера для усовершенствованного приемника трасс, поддерживающего различные способы распределения данных в памяти
    и их экспортирование через PCIe или Ethernet подсистемы.
\end{enumerate}
